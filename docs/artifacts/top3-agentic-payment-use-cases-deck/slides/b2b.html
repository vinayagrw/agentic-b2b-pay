1. B2B supplier payout agents

Problem

An agent can pay the wrong supplier. Most supplier systems still do not connect.

Root cause

Only 13% of suppliers have fully linked systems. Under UCC 4A the loss stays with the payer if the bank followed procedure.

Dollar value

About $100M a year in agent payments at Melio. Vendor’s own figure. 38% of B2B buyers already use agentic AI.

Status today

Live at small-business scale since June 2026. Visa pilot with BILL and Billtrust. Corpay Agent Card, 29 July 2026.

Sources: C291, C292, C293, C298, W2, W3. UCC 4A reading is a law firm view.

The strongest near-term case. The key control is the payee change guard: an agent should never edit bank details or release money. Liability is contractable, unlike consumer checkout. Our demo build now has this guard: a bank-detail change needs a recorded call-back and a second person, and payments are held while it waits. It also has a mandate-bound virtual card, one card for one approved order.
