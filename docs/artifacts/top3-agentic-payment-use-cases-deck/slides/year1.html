The agent holds no release tool. No stablecoin in Year 1. Steps 3, 5 and 8 are built in our demo. Our view: build this first. It pays back soonest.

Read left to right, top row then bottom row. The agent drafts from an approved invoice. The mandate check verifies the platform signature and the passkey mandate. The payee guard runs the invoice match, the sanctions screen, the US account check and the bank-detail change check with a call-back. The rail is picked before release, so the release matrix can judge payee status, amount and rail together. Release writes a signed assertion, and the bank connector refuses anything without it. Returns and status come back to the evidence ledger and the ERP. Each paid order gets one dispute evidence record. In the demo, chat approval is a mock preview and all money is sandbox or simulated.
